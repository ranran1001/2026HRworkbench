# 2026 HR 工作台

这是一个可在本地浏览器打开的 HR 工作台。当前版本包含组织与岗位、招聘与人才获取、入职档案与合同、考勤与假勤、薪酬社保福利、绩效培训与人才发展、员工关系与合规/离职、HR 数据与运营八个模块。

## 打开方式

1. 解压工作台压缩包。
2. 用 Chrome 或 Edge 打开本目录的 `index.html`。
3. 组织岗位模板位于 `assets/组织与岗位工作簿-v0.1.xlsx`，也可在网页首页下载。

Excel 上传和导出需要网页加载 SheetJS 组件，因此浏览器需能访问 jsDelivr。工作数据保存在当前浏览器本地，不会自动同步到其他电脑或用户。请勿把未脱敏的真实人事敏感资料放入公开演示版。

组织与岗位模块的手动验收步骤见随交付提供的《组织与岗位模块手动验收清单》。

## 资料原表（v0.20）

首页“资料原表 · 首版下载”提供 8 个模块的原始 Excel 候选，文件内容原样保存在 `assets/source-templates/`。使用者确认工作簿中的个人信息均为示例数据。原表适合先查看/试用；导入工作台台账前，请使用工作台模板核对字段。薪酬表中的税务、社保和公积金规则需按实际地区与期间复核。

## 线上验收版 v0.22

作品集提供“作品集展示”和“下载完整版 PDF”两个入口。展示窗口按自我介绍（第 3–5 页）、成果展示（第 6–15 页）、规划展望（第 16–17 页）分区，每个分区使用原 PDF 页面渲染的 PNG 纵向连续展示；“更多……”预留给目标公司定制方案。原始 18 页 PDF 可完整下载。当前 Site 为私有访问。
